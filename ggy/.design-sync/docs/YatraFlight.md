The journey, flown. A pinned map of western India: the camera settles on
Gujarat, follows a line south to Maharashtra, then on to Goa. Each state
fills with its photograph as the marker reaches it, and its card comes up.

**Use.** The pinned map flight over Gujarat, Maharashtra and Goa, with a card for each state. Takes no props: a full-width homepage section that renders its own copy and photographs from the site content. Place it directly inside `<SiteShell>`, in page order, between other sections.

## Example

```jsx
// const { YatraFlight } = window.Ggy;  (inside <SiteShell>)
export const ThreeStatesOneJourney = () => <YatraFlight />;
```
