The field: the lecture hall and the open country in one frame, divided by
a handle the reader drags from one into the other. Then the idea
of the Yatra in the brochure's own words.

**Use.** "The field is the classroom": paper ground, the hall-and-field comparison and the idea panels. Takes no props: a full-width homepage section that renders its own copy and photographs from the site content. Place it directly inside `<SiteShell>`, in page order, between other sections.

## Example

```jsx
// const { Field } = window.Ggy;  (inside <SiteShell>)
export const FieldIsTheClassroom = () => <Field />;
```
