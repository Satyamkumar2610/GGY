Departure: the crimson band after the opening. The states of India draw
themselves in beside the claim, and the four words from the brochure cover
open across the full width of the page as the band is crossed.

**Use.** "Governance, on the ground": the deep crimson statement with the map of India and the route marquee. Takes no props: a full-width homepage section that renders its own copy and photographs from the site content. Place it directly inside `<SiteShell>`, in page order, between other sections.

## Example

```jsx
// const { Departure } = window.Ggy;  (inside <SiteShell>)
export const GovernanceOnTheGround = () => <Departure />;
```
