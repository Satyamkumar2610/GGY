Ten questions, answered only from the 2025 brochure and the confirmed
route. The left column holds still while the answers are read: the title,
a counter for the open question over the outline of India with the
upcoming edition's states filled, and a way to ask the team directly.

**Use.** "Questions, answered": the accordion beside the map. Takes no props: a full-width homepage section that renders its own copy and photographs from the site content. Place it directly inside `<SiteShell>`, in page order, between other sections.

## Example

```jsx
// const { Questions } = window.Ggy;  (inside <SiteShell>)
export const QuestionsAnswered = () => <Questions />;
```
