Joining: the one action available today, the upcoming edition set as a
pass whose fields are still blank, a self-check, and the admission process
as printed for 2025, its five steps set as a climb.

**Use.** "The journey changes the way you see governance": the pass, the readiness check, the admission process and contact, on deep crimson. Takes no props: a full-width homepage section that renders its own copy and photographs from the site content. Place it directly inside `<SiteShell>`, in page order, between other sections.

// const { Joining } = window.Ggy;  (inside <SiteShell>)
