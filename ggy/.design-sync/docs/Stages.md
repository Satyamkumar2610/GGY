The learning journey: four stages, in order, on the crimson ground. On
wide screens the section holds and the four names turn past like a reel:
the stage being read opens to its full width and colour, its neighbours
wait condensed above and below, and its description comes up beside it.
Elsewhere it is a plain ordered list.

**Use.** "Four stages of a personal learning journey" on deep crimson. Takes no props: a full-width homepage section that renders its own copy and photographs from the site content. Place it directly inside `<SiteShell>`, in page order, between other sections.

## Example

```jsx
// const { Stages } = window.Ggy;  (inside <SiteShell>)
export const FourStages = () => <Stages />;
```
