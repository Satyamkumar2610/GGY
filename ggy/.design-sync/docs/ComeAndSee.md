Come and see: the photograph opens from a rounded window to full bleed and
the invitation rises over it. Admissions and contact follow directly.

**Use.** The full-bleed invitation over the cohort photograph. Takes no props: a full-width homepage section that renders its own copy and photographs from the site content. Place it directly inside `<SiteShell>`, in page order, between other sections.

## Example

```jsx
// const { ComeAndSee } = window.Ggy;  (inside <SiteShell>)
export const ComeAndSeeHowIndiaIsGoverned = () => <ComeAndSee />;
```
