Field photographs from past editions, as a stack of prints. Each print
pins in turn as the page scrolls and the earlier ones shrink and dim
beneath it. Any print opens in a full-screen viewer.

**Use.** Field photographs from past editions, dealt as a scroll stack, each opening full screen. Takes no props: a full-width homepage section that renders its own copy and photographs from the site content. Place it directly inside `<SiteShell>`, in page order, between other sections.

## Example

```jsx
// const { FieldGallery } = window.Ggy;  (inside <SiteShell>)
export const FieldPhotographs = () => <FieldGallery />;
```
